# BEAA 里程碑与自动流转规则

## 状态定义
- TODO：未开始；IN_PROGRESS：开发进行中；BLOCKED_HUMAN：必须人工介入；VERIFY：待测试证据；DONE：已获验收证据。
- 没有通过的 CI 或可复现的测试结果，不得标记为 DONE。
- 无设备的浏览器演示与系统级应用限制必须在状态和对外文案中分开。

## 自动任务执行规范
1. 阅读本文件和最新代码/CI状态；按 M1 任务顺序选取可自动执行的未完成项。
2. 先写或补验收测试，再实现功能；尽可能将代码和验证放到可回退的提交。
3. 每次变更附提交/PR链接、测试证据与剩余阻碍。
4. 不覆写 master、不强推；涉及架构或安全边界重大变化需要人工确认。
5. 若子项需要人工操作，标记 BLOCKED_HUMAN 并自动转移到下一个独立任务；不因单点阻碍中断其他工作。
6. M1 通过验收后停止继续修改，汇报交付物与 M2 所需人工条件。
