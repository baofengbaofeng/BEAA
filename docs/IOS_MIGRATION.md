# iOS 跨设备迁移

`TransferMigration` 是独立于同机加密备份的便携格式。现有备份仍依赖设备 Keychain 密钥和可信高水位；旧修订、缺失锚点或外机备份不因此获得恢复权限。

家长在源机验证后输入至少 12 个 UTF-8 字节的长口令、重复口令，并明确确认导出及停止使用原设备。格式固定为版本 1、PBKDF2-HMAC-SHA256 600,000 次、32 字节随机盐、256 位密钥、CryptoKit AES.GCM 随机 nonce 和固定格式 AAD。版本和 KDF 参数必须完全匹配；不能用攻击者指定的高迭代数耗尽资源或低迭代数降级。包上限 16 MiB，明文上限 8 MiB；外层 JSON 及 GCM 标签防止篡改。

## 数据与额度规则

- 目标必须已经成功建立可信的全新账本，锚点修订严格为 1，且内容除了随机回合编号和日期外与默认初始状态相同。任何使用、配置更改、迁移、历史或额外修订都拒绝覆盖；恢复为零也不能绕过检查。既有目标须保留两端资料，不提供清空或绕过高水位的按钮。
- 恢复题库、当前及待生效规则、学习历史、答题细节、未完成挑战、回合编号、已用每日和本轮预算、休息进度、临时及应急审核历史。
- 源机若有有效临时或应急授权，导出的副本首先对未测使用采取保守结算，再移除授权。不会返还未计量额度。便携编码器不改写来源；系统监控开启时，界面会在编码前先处理回执并持久结算来源账本。
- 不传递 PIN、生物识别设置、Keychain、设备 ID、云端信任、云命令去重状态、系统监控配置、有效临时或应急授权、跨设备无效的连续时间休息锚点、控制修订。云端和设备身份不在 LearningState 之外被读取或写入。
- 导入以目标现有设备密钥在下一修订提交；不修改源或目标 Keychain 身份。持久化 `migrationConfirmationPending`，业务与系统使用必须保持锁定，即使重启也不自动启用。
- 家长重新验证并点击“家长确认今天并保留已用预算”后，保留源每日和本轮已用秒数、阶段及答题进度，把日期设为今天，并清除待确认标记。即使源记录是前几天的，也不清零迁移当天预算。未来来源日期拒绝确认，先修正时钟。下一天正常的家长换日确认仍按原规则运行。
- 确认本身不提供系统权限、监控或有效授权，必须按本机流程重新设置。完成回调结束当前家长会话。

文件选择器返回后、密码派生之后及最终可信提交之前再次检查家长授权；选择、确认是分开的操作。离开页面或应用非活动时清空口令、待导入文件和导出文档；Swift 字符串/框架副本无法保证物理内存擦除，不宣称可安全抹除全部运行时副本。

离线文件不能证明源设备已经停用，也不能阻止在另一台全新设备重复导入。此格式是家长授权的数据搬迁，不是跨设备全局唯一额度协议；源界面明确要求停止使用原设备。若需要强制唯一活跃设备，需另行实现在线撤销与可信设备注册。

## 验证状态

新增 `BEAATests/MigrationTests.swift` 覆盖跨密钥导入、原预算保持、显式确认、旧日保守确认、错误口令、GCM 篡改、KDF/版本拒绝、超限、目标占用、授权过期、重复导入与未完成挑战。现有同机备份反回滚测试继续保留。

遵照用户要求，本轮不执行 Apple 编译、模拟器或 XCTest。需后续在 macOS/Xcode 编译并运行 MigrationTests 和安全存储/平台监控相关 XCTest，验证文件选择器授权失效、前后台切换、挂起和受保护数据不可用场景。源码检查或 Node 检查不替代这些验证。

集成保护：`AppModel.prepareMigrationExport` 在导出前处理系统回执并保守结算普通使用阶段的未确认额度；回执/存储故障拒绝导出。迁移入口使用滚动容器。新设备初始家长配置和有效家长会话期间不计本应用练习时间，从而保持新账本可导入；已开启的系统范围仍由系统回执计入，不以页面暂停返还预算。
