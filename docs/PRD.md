# 学知守护 PRD v0.1

## 目标
为小学阶段儿童提供使用时间管理、语文数学英语答题解锁、休息提醒和家长控制。产品界面平台中立，横竖屏自适应。

## 角色
儿童使用、答题、休息；家长设置时间规则、题库难度、授权及查看统计。

## MVP 规则
- 有效使用累计达到一轮30分钟时触发挑战；5分钟/1分钟前提醒。
- 每日累计默认上限120分钟，独立于答题通过资格，不可通过答题突破。
- 每轮默认5题，严格模式5题全部正确；答错给出解释并提供再练习。
- 答对后获取**待生效的**下一轮30分钟资格，仍须先满足默认10分钟的休息条件。
- 学科语数英、年级1至6年级可选；单选、判断、数值填空优先。
- 断网使用本地题库；跨应用切换和横竖屏旋转不重置计时或答题进度。
- 家长密码保护规则，临时授权有明确有效期与审计记录。
- 权限缺失时应提示真实限制，绝不假称仍执行系统级管控。

## 核心页面
1. 儿童主页：剩余30分钟、今日已使用、每日120分钟上限。
2. 学习挑战：科目年级、5题进度、单选大按钮及错题讲解。
3. 成功解锁：资格说明和10分钟休息提醒。
4. 家长设置：周期、总量、学科、题数、难度、密码及记录。
5. 异常/权限页：授权状态、限制能力和恢复指导。

## 优先级
每日上限/禁用时段 > 必须休息 > 答题通过资格 > 允许使用。紧急求助与系统必要操作不应被阻断。

## 验收前提
跨应用统计、限制第三方应用、限制后引导答题、答题后恢复权限，必须先在 MatePad 11 / HarmonyOS 4 上验证授权和系统能力。能力不足时MVP必须明确降级范围。见 [验收测试](../tests/ACCEPTANCE.md)。
