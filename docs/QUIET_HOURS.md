# 每周禁用时段

家长验证后，在「家长设置 / 家长空间」选择星期、开始和结束时间，添加禁用时段。可添加最多14条；删除后立即生效。空列表表示关闭。开始和结束不能相同。

例如选择周日21:00–07:00，表示从周日晚21:00暂停到周一早07:00；不是周一晚开始。开始时刻包含，结束时刻不包含；多个时段重叠时，只要任一时段仍有效就保持暂停。

禁用期间可查看记录、由家长调整时段或导出摘要；应用内使用、开始/继续挑战、完成休息及分配临时时段暂停，既有阶段和累计保留。休息进度只累计非禁用时间；新增/删除规则先结算旧规则下已经发生的休息，不能通过删除时段把过去暂停时间补算。当前临时使用记录在进入或跨过禁用区间时终止，结束禁用也不会自动恢复该记录或增加额度，仍需家长结束临时模式。

本功能根据设备当前本地星期和时间判定，不提供可信时钟，不限制其他系统应用。更改时间/时区会影响判定；原有时间回拨保护保持有效。无效的时间样本暂停操作。夏令时重复或跳过的本地时刻按实际观察重新判断。原生版本对跨越分钟边界的采样采取保守计时，不补算不确定区间。

旧存档缺少禁用时段字段时按关闭迁移；明确损坏的规则或休息累计进入恢复保护，保留原始记录。家长时段编辑与一般题库/挑战设置独立，可在挑战和休息期间更改，不清零现有累计。并发标签页继续使用原有锁和版本冲突保护；其他页更改后需重新家长验证。

## 开发与验证

- JavaScript规则：`shared/domain/quiet-hours.mjs`；边界、重叠、跨周、输入校验和休息扣除由同目录测试覆盖。
- `npm run sync:preview`同步共享规则到离线页面，`npm run build:native-preview`同步鸿蒙资源。
- `npm test`运行规则、存储、页面状态和打包测试。
- `BEAA_CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`运行真实浏览器交互及无障碍检查；file://用例仍受本环境策略限制。
- Swift原生规则和编辑器：`apps/ios/BEAA/QuietHours.swift`及`QuietHoursEditor.swift`；XCTest在`QuietHoursTests.swift`。项目结构检查通过不等于Apple编译或真机通过；当前Linux未提供Swift/Xcode。

已实际查看手机和平板的编辑器及暂停页截图，保存在本次忽略输出目录`test-results/quiet-ui/`。新增提示通过现有离线拼音组件显示。
