# 无需安装的浏览器规则检查验证

日期：2026-11-05。基于 dev bcb7acb，独立分支 feature/browser-self-check。保持已验收 M1 源码不变，本轮新增独立验收工具。

## 交付与范围

`npm run build:browser-check` 生成 `dist/beaa-browser-check.html`。用户直接浏览器打开，点击开始，下载 JSON 报告；无需安装 Node/Python 或等待实际十分钟。源码内嵌并校验 SHA256，替换 iframe 存储/锁/时钟后才执行实际 MVP，使用 DOM 控件驱动，不直接修改内部业务状态。摘要是完整性检查，不是数字签名。

检查涵盖失败作答/错题/统计、10分钟休息边界、120分钟硬上限、内存快照与宽窄尺寸恢复、家长PIN/设置恢复、时钟回拨。真实站点数据不被读取或更改，无网络上传。隔离失败标记 unsupported，整体 incomplete；源码校验失败整体 blocked。

## 不在此报告的证明范围

内存快照不是磁盘持久化验收；虚拟尺寸不是设备旋转事件验收；私有队列不是多标签页真实锁验收；虚拟时间不是可信计时/真实休息采集。无原生SDK编译、HAP、签名、目标设备应用限制证据。无行为干预或医学健康效果验证。M2继续BLOCKED_HUMAN。
