## 行为

源session必须已通过并待休息；稳定restId、revision与完整核实区间控制迁移。同启动连续休息才累计，active/unknown清零；间隙后重新计入确证区间，boot变化/时钟回退或重叠会重新建立边界，不沿用旧额度。最近同命令重试不计双倍，跨ID和过期revision拒绝。毫秒边界保守取整，不调用墙钟。

完成除需要足量证据外，还要求当前可信同启动检查点不早于证据边界；检查点本身不补时间。保存完成receipt后重复完成返回原结果，不增加revision。完成保持日累计，使用既有finishRest结束周期/挑战。JSON恢复严格校验来源会话、区间/边界/revision和完成关联，未知或损坏数据不修补/清空。

## 证据边界

全部区间/bootId/检查点为合成输入，平台必须证明完整区间条件真实性；两个空闲采样点或前台倒计时不满足契约。ready不表示当前系统已允许恢复，历史完成receipt不重新授予设备权限。

没有真实设备测量、原生存储事务、跨阶段quiz/rest原子切换、多进程恢复或断电测试。demo独立quiz/rest文件只验证组件编解码；端到端生命周期、真实日切换与策略更新、受保护存储/CAS、防回放仍需平台集成。ArkTS/SDK/HAP/签名/目标设备及权限验收门禁保持未通过。
