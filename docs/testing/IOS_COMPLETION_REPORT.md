## 集成自查修正

- 系统回执按累计 MAX 合并，持久化成功后确认处理；不重复计入前台秒数，也不把旧日期/代次回执带到新日。
- 监控替换、停止、到期和提前结束应急授权保守结算未确认预算；所有提交前先检查已结束的活动系统授权。终止回执先结算再观察用时，避免延迟回执/时间回拨返回额度。
- 禁用时段编辑同样先结算，不通过重启监控重获当前预算。
- 云端记录验证创建者与最后修改者、目标、可信参与者、修订、期限及重放；本机导入/修改重新检查实时家长授权。
- 默认方案不开启能力、不嵌入扩展；用户自有标识通过 User.xcconfig 传到应用和三个扩展。
- 独立源码审查发现的相关重要问题已修复；最终变更仍没有 Apple 编译/运行证据。
