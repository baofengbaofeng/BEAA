# SQLite一致备份与只读检查验证（2026-11-05）

基于devd0ebe56（PR #19已合并），扩展云端SQLite参考适配器；不更改共享业务快照schema、CAS契约、浏览器MVP或原生UI。

## 行为与安全边界

backup使用SQLite Online Backup API，在固定源读事务中核对格式/摘要/metadata后复制到独占新0600文件，再核对目标与源事务相同，Node完整业务codec再次验证。副本metadata只含lifecycleId/revision/snapshotSha256，源revision和回执不变。目标及祖先私有权限校验复用既有规则；既有文件/源自身/符号链接不覆盖。

inspect使用SQLite mode=ro，完整校验后仅输出metadata，不修改源或副本。CLI严格校验参数，固定错误消息不回显路径/载荷。旧副本检查不回滚当前账本；没有restore/failover功能，不能通过旧副本重新发放资格。
