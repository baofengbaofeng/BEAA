## 本轮交付

- 共享协议 v2：判断、精确数值、分数、显式绝对容差；v1兼容；固定快照、首答评分、反馈、历史与真实SQLite资格往返。
- 网页/鸿蒙离线：复杂题型、历史错题练习统计、独立应急授权、实际家庭服务客户端、54个可选择课程草稿包。原有禁用/上限/休息与累计保护保持。
- 家庭服务：Node真实HTTP服务、独立家长页、长口令/设备角色隔离、加密原子存储、单次配对/撤销、修订/时限/重放防护、持久回执独立补发。默认关闭，未远端部署，不与iOS CloudKit互通。
- 鸿蒙原生：独立PIN、失败冷却、凭据版本和后台撤销；加密RDB候选；原生前台练习资格、三道固定首答、周期/休息/练习日账本和不可重复回合来源；生命周期/异步竞态保护。练习功能不是跨应用使用计量或设备执法。
- 中文拼音与布局：原生文字、动态状态、输入提示、按钮及系统通知附离线拼音；原生练习默认折叠、展开可滚动，Web区域有界。浏览器家庭/课程面板按360像素宽度检查。
- iOS迁移：独立口令加密格式、新目标导入、旧累计和未完学习保持、导入后确认门禁、拒绝覆盖已使用账本；系统监控开启时先处理回执和保守结算再导出。
- 课程：18组年级/学科、108单元、288道原创练习、54个分级包，具有摘要绑定的教师审核和发布门禁；全部仍待审核，不等于完整六年课程。

## 自查和审查修正

- 已应用指令的回执即使跨过五分钟指令期限也独立重试；服务保留七天重试证据，拒绝矛盾重复回执。撤销设备不永久占用活动设备名额。
- 浏览器CAS竞争和写入失败回滚到可信最新状态；课程载入与指令均使用状态锁，失败不会只在内存偷偷更换题库或额度。
- 鸿蒙声明INTERNET，但实际rawfile Origin/TLS/CORS仍需设备记录，默认不开放null来源。
- 原生认证/改PIN在耗时派生、后台撤销和授权到期后不会恢复身份或修改凭据；前台开始/采样的异步读与后台会话代次绑定。
- 原生计时保留小数余量，连续999毫秒回调可累计；超过三秒的中断不补计。原生通知标识和取消路由不因拼音改变。
- iOS导出处理普通系统阶段的未测额度，迁移页面可以滚动；初始家长配置不消耗新账本，待确认迁移不能开始学习或发放使用资格。
