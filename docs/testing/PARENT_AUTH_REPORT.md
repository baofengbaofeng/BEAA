# 家长验证与受保护报告验证（2026-11-05）

基于dev8ad47df（PR #20已合并），新增Linux本地家长身份参考和SDK无关报告授权接口；不修改浏览器MVP、guardian schema/额度或原生UI。

## 实现

6–12位ASCII数字PIN，PBKDF2-HMAC-SHA256 600,000次、16字节独立随机盐、32字节摘要；私有独立SQLite数据库记录家庭scope、凭据版本、失败计数与启动/单调冷却。5次失败冷却5分钟，跨服务重开保留计数，启动变化/单调回退保守处理。PIN不落明文/argv/日志。

成功验证发放256bit随机token，实例内仅存SHA256索引，最多16个，5分钟单调到期且不续期；注销、服务重开、换PIN/凭据版本变化撤销。报告在异步读取前后核对授权与家庭scope/version，仅包含已完成历史，不修改账本或返回未答题快照。
