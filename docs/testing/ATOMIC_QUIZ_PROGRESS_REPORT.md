# 单轮答题与归档一致性验证（2026-11-05）

基于dev73f12a0（PR #12已合并），补齐测验服务与学习历史之间的状态迁移衔接。原先需上层分别保存两个载荷，现在可提交一个组合快照。代码不改浏览器MVP，也未实现原生存储或系统权限。

## 验证行为

- 仅未作答active测验建立单轮progress；每次答案推进revision。末题推进及学习归档在一个纯迁移内完成，通过/失败均记录；通过仍需休息且日累计保持。
- 命令携带稳定轮次ID与期望revision。原提交完整重试视为duplicate，选择冲突、未来revision和其他轮次被拒绝；复用同一题ID的新轮不能接收旧命令。
- 严格恢复检查完成事件与历史记录内容，缺失/冲突记录或知识点、未知字段/版本、矛盾revision、超长文本均拒绝，不自动修复或创建新会话。真实outside_window完成事件明确记录该结果。
- controller通过read/CAS端口提交；比较轮次ID和revision，提交完整快照。反馈只在端口确认提交、或读取证实命令已提交时返回。命令副本在异步read前捕获。

## 证据边界

本轮证明纯业务迁移和符合契约的测试端口下的协调行为，不证明任何平台后端已具备事务、认证或持久性。生产端口仍需原子比较与持久写入、完整读、长期唯一轮次ID、认证/CAS/防回放、跨轮生命周期事务和可信时间。单进程示例不提供多进程锁/fsync，不是断电或设备崩溃证据。原生SDK、ArkTS、HAP、签名、设备权限与真机验收未执行，M2保持BLOCKED_HUMAN。
