# 统一生命周期与阶段迁移验证（2026-11-05）

基于dev7cb306f（PR #15已合并），此前答题和休息各有可恢复载荷，但示例阶段文件分离。本轮统一为一份生命周期快照与一个存储端口，不改已验收浏览器MVP或原生UI。

## 行为

全局revision跨阶段递增，round确定性ID不因学习历史淘汰而复用。顶层history仅保存一次；通过末题同次归档与创建休息，失败保留记录可重练；休息完成同次回到普通session、保留账本/历史及最近完成证明。可信跨日保留部分题目或休息要求，完成记录的原日期不变。默认4轮30分钟使用后120分钟日硬上限锁定，不能用答题突破。

最近事件回执匹配才重复成功，旧revision/冲突命令拒绝。统一controller异步读取前复制命令与题库，校验并编码全部新状态后调用一次CAS比较lifecycleId+revision；未确认写入不返回成功反馈。恢复严查阶段、回执、原会话/题库/历史关联，未知或损坏记录不自动建立新账本。

## 边界

纯迁移及符合契约的测试端口验证不证明生产存储已经具备原子性、持久性、认证或防回放。单文件demo为同进程独占的同步比较/rename，无多进程锁/fsync或真实进程/设备崩溃测试。全部usage/日期/区间/boot/checkpoint为合成输入，不能用于声称跨应用计时、真实离屏休息或系统限制。

家长认证/策略更新/临时授权、真实平台输入与系统操作不在该共享聚合中；平台必须验证身份及来源、原子持久化后才执行设备动作，duplicate不应重复发放资格。原生ArkTS/SDK/HAP/签名/目标设备和权限门禁仍待验证，M2未验收。
