# 家长设置写入与累计保留验证（2026-11-05）

基于dev6d9eb22（PR #21已合并），把现有家长身份参考接入真实设置写入，保留默认120分钟与既有答题/休息约束，不改浏览器MVP或原生UI。

## 实现

parent-policy只接受完整set_policy，前后授权/scope/version校验后一次CAS；普通生命周期controller拒绝该类型。并发修改不会静默覆盖，提交结果未知重读原回执。普通/日锁/已失败测验立即应用，答题或休息中pending，固定当轮规则并在安全边界生效；历史成绩不追溯重判。

schema2新增独立dailyUsageSeconds，保留降限后超出新cap的实际已用值，内部session仅作min(actual,cap)引擎投影。旧schema1先冻结validator严格校验再内存迁移，read/inspect/backup不重写旧库，下一成功CAS写payload2；SQLite表仍user_version1，领域session/quiz/rest格式不变。

## 证据边界

权威累计/已核实使用与休息输入仍依赖可信平台，示例数据为合成；本轮未赋予系统限制权限。配置生效时机是明确的应用规则：当前挑战及所需原休息保持，下一次允许使用前应用；父母增加周期/上限可改变后续使用，答题本身仍不能突破上限。

授权与账本分库，CAS前最后一次成功授权是接受点，不是跨库原子撤销事务。私有权限/摘要不防同UID/root篡改/回滚，禁止把payload2丢字段降版或用旧备份恢复额度。原生设置UI、格式迁移/受保护存储、临时放行、SDK/HAP/签名及真机/断电验收仍未完成。
