# 学习历史与统计验证（2026-11-05）

基于dev a1b9218（PR #10已合并），实现SDK无关的学习记录服务，不修改已验收的浏览器MVP或原生UI。

## 行为与范围

完成的通过/失败测验可归档固定题目、所选答案、完成事件及原通过阈值；只答部分不能归档。保留最近1–200轮，同保留ID同内容重试无副作用，同ID冲突拒绝，较旧事件不会挤掉新记录。查询从固定答案计算正确数/通过结果，支持日期/年级筛选、逐次错答及学科/知识点分布；空准确率为null，多标签分别计数。数据与规则授权隔离，不发放资格。

JSON恢复严格校验版本、字段、日期、题序、合法选项、完整性、唯一ID及排序，错误不自动清空。超出5,000,000码元拒绝，revision仍是元数据。含标准答案/儿童学习数据，应由可信控制层与受保护存储保管。原生层仍需认证、CAS、可靠完成事件、长期去重及原子提交；纯函数不提供这些能力。
