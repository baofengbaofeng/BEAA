# 拼音界面与客户端验证

日期：2026-11-09（北京时间）。

## 网页与鸿蒙离线资源

所有中文文本默认添加带声调拼音，覆盖导航、静态说明、运行时提示、家长表单、题干、答案、导入题库和浏览器规则自查页面。使用锁定的 pinyin-pro 3.29.5（MIT），在本机完成转换，不上传文本。输入框和 JSON 原始数据不被改写。选择框用纯文本拼音；常规文字使用 ruby 和 rt。读屏保留原始中文名称，避免重复读出拼音。注音依赖词典，罕见专名/多音字仍需人工审核，不等于教师审定。

实现源：shared/ui/pinyin-ui.js；运行 `npm run sync:pinyin` 同步嵌入读音库及辅助组件。修改网页后运行 `npm run build:native-preview`。`npm run check:sources` 检查嵌入代码及原生页面同步。第三方许可随嵌入库保留在每份 HTML 中。独立 HTML 与原生离线页无需网络加载依赖。

布局调整：响应式导航网格、可换行的拼音与汉字、输入与标签自适应、长题目与错题间距、最低 48px 操作目标、清晰焦点轮廓。新增浏览器回归验证声调、词语读音、动态提示、导入文本的 HTML 安全、320px 窄屏及放大字体。原有浏览器测试继续验证挑战、休息、每日上限、PIN、多标签与持久化恢复。

手机及平板截图在本次测试输出 test-results/ui-review/（忽略目录，不作为永久验收证据）。真实读屏、目标设备 WebView、字体及离线 file:// 仍需设备验收。
