# 共享题库与答题服务验证

基于dev b6a1dcb（PR #9已合并），新增SDK无关业务服务，不修改已验收的浏览器MVP和原生UI。

## 实现

- 共享样例原有3题，无法满足默认5题；扩充为5道已核对答案的三年级语数英样例，保留原题ID，增加可选知识点标签。
- 校验题库、重复ID、稀疏数据、选项歧义和答案引用。按真实年级、学科和知识点并集过滤，稳定轮询非空学科池；不足时拒绝，不重复凑题或改标签。
- 提交接口仅接受questionId/chosen，从本轮固定题快照判分。公开当前题不含答案/解释；复习接口只提供已答题。非法选项、旧题重投和客户端自报评分被拒绝，输入状态不被修改。
- QuizAttempt格式结合规则快照和题目/答案快照；恢复时核对所有已存评分，题库文件后续修改不改变本轮答案。重启恢复不需重新读取当前题库。
- demo实际组卷、以模拟选项答题、临时文件保存/恢复后继续，合格后仍需休息且不清零日累计。

## 证据

完整npm test80/80，通过；新增17项题库/服务测试。npm run demo成功。原始输出见shared-quiz-node-results.txt和shared-quiz-demo.txt。

覆盖默认5题跨学科组卷、其他年级及知识点过滤、题量不足、旧格式兼容、输出隔离、已知样例答案、基于固定答案判分、错误解释、失败重试、非法/重复提交、磁盘恢复、评分篡改不一致、跨日恢复、公开数据和复习数据边界。独立审查未发现Critical/Important问题，并额外检查了非满分阈值恢复及嵌套JSON字段拒绝。

## 边界

数据校验不证明题库来源/语义真实性，包含答案的attempt只能由可信控制层与受保护存储持有。revision仍为元数据，认证、事件去重、CAS/原子提交及抗回放需平台实现。未接浏览器或原生Preferences，未进行ArkTS编译、HAP、签名或设备验收；M2门禁状态不变。
