# 网页与鸿蒙离线端家庭服务

本轮提供可实际运行的 Node 家庭服务、独立家长页和显式配对的客户端。不是演示成功回执，也不是 iOS CloudKit 的网关；iOS 继续使用其独立家庭分享方案。未部署远端服务。

## 本机启动

需要 Node20+ 和 `npm ci`。在自己的终端中设置以下变量；不要把真实口令或密钥提交仓库。

```sh
export BEAA_FAMILY_STORE_KEY="$(node -e "process.stdout.write(require('crypto').randomBytes(32).toString('base64'))")"
export BEAA_PARENT_PASSWORD='替换为至少十二字符的家长长口令'
export BEAA_FAMILY_ORIGINS='http://127.0.0.1:4173,http://localhost:4173'
npm run family:serve
```

密钥需安全保留供重启使用；换密钥不能解密原库。默认只监听 `127.0.0.1:8787`，数据库为忽略的 `local-data/family.enc`。打开 `http://127.0.0.1:8787` 登录家长页，生成十分钟有效的单次配对码；在网页预览的已验证家长设置中填写服务地址和配对码，确认开启。家长长口令不要输入孩子页面。服务创建后改环境口令不会替换数据库内的既有口令。

默认不开启任何上传。关闭本机连接会删除本机设备令牌；家长页可撤销服务端设备。客户端只上传计数、规则及修订，不上传 PIN、密钥、题目、答案和完整学习账本。设备令牌只有上传摘要、领取自己的指令及提交回执权限，不能创建指令或获取其他设备。

## 部署与来源

跨设备使用由部署者在自己的服务器运行同一服务，并通过 HTTPS 反向代理暴露。服务地址必须是 HTTPS，只有本机开发允许 loopback HTTP。设置 `BEAA_FAMILY_ORIGINS` 为实际客户端页面的精确 Origin，逗号分隔；没有通配符或默认开放来源。协议仅接受 JSON 和 Bearer 令牌，没有 Cookie 会话。

鸿蒙工程已声明 INTERNET 权限。rawfile WebView 的实际 Origin 必须在目标设备记录并配置：若实际为 `null`，部署者可明确加入 `null`，但它也代表其他不透明来源，因此仍依靠设备令牌鉴权。默认拒绝 `null`，不能仅凭浏览器测试宣称鸿蒙网络可用。真实 WebView TLS、CORS 和权限仍待验收。

## 一致性与安全边界

- 家长口令 PBKDF2-SHA256 210000 次，五次失败冷却十五分钟；会话一小时，仅存父页面内存。设备令牌随机32字节，服务器仅存摘要。
- 私有文件 AES-256-GCM，随机 IV、固定 AAD、原子替换与 fsync；CLI 在加载数据库前持有独占进程锁。异常退出留下锁时先检查原进程和文件，再由部署者处理，不静默抢锁。
- 指令绑定设备、UUID、预计修订和五分钟期限。客户端先消费 ID 再保存业务，崩溃时可保守拒绝而不会重复授权。拒绝过期、回放、旧修订；挑战/休息/禁用时段/每日上限继续优先。
- 客户端独立重试已保存回执；服务保留最多七天的重试证据，重复回执必须完全相同。达到有界容量会明确拒绝新请求。
- 服务按单进程独占运行，不提供多节点高可用。密文存储不提供独立硬件高水位，不能抵抗服务器文件整体旧备份回放；设备端的修订和授权校验仍不可省略。
- 浏览器本地数据和脚本可被设备持有人修改，本地 PIN 与远程客户端不是原生防篡改执法边界。网页用时始终是明确模拟值；家庭连接不会让它变成整机用时。

## 已验证与待验证

Node 真实文件/HTTP 测试覆盖角色隔离、单次配对、加密重开、旧修订、撤销、过期及回执重试。浏览器端到端使用真实本机服务验证配对、指令和丢失回执后的补发。生产 TLS、实际多人家庭部署及鸿蒙 WebView 留给环境验收，不由此宣称已运行。
