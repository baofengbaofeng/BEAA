# MatePad 11 / HarmonyOS 4 真机能力验证（P0）

## 验证目标
验证第三方应用是否能在**合法官方权限**下检测跨应用使用时长、执行纳管应用限制、引导进入自有答题页、答题后恢复访问。如果不支持，应明确限定为应用内使用时间管理与答题学习，而非全设备防沉迷。

## 测试矩阵
| ID | 步骤 | 验收点 |
|---|---|---|
| P01 | 未授权启动 | 显示未授权，不谎称已开启 |
| P02 | 授权后分别打开两个非本应用 | 能否获得可信的有效使用时间 |
| P03 | 30分钟到期 | 能否限制被纳管应用 |
| P04 | 受限状态打开答题页 | 不依赖用户自愿返回 |
| P05 | 答题全部正确但休息未完成 | 仍保持限制 |
| P06 | 已满足休息条件且未达日上限 | 限制确实解除 |
| P07 | 累计超过120分钟 | 答题无法绕过日上限 |
| P08 | 切应用、息屏、分屏 | 统计和执行策略可靠 |
| P09 | 进程终止、设备重启 | 管控状态能复核和恢复 |
| P10 | 撤销权限/卸载 | 提示真实失效状态，安全退出机制可用 |

## 操作原则
- 优先检查官方公开 SDK、权限声明及受限权限申请政策。
- 不用“全屏悬浮窗”“无障碍模拟操作”声称实现了不可绕过的系统限制。
- 不干预紧急求助和必要系统操作。
- 发现无法合法可靠执行 P02-P06 时，结论为 **No-Go（全设备强制管控）**；允许独立继续 UI、题库与业务规则开发，但必须调整对外功能描述。
