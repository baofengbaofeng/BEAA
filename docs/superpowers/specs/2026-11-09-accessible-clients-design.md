# 儿童拼音界面与原生 iOS

用户授权按实现者判断直接开工。选用 SwiftUI 原生客户端；网页与鸿蒙继续复用同源离线页面。所有中文提示默认带声调拼音，包括动态错误、题干、答案、家长设置和规则自查。读音转换离线执行，按词语识别多音字；不发送儿童内容到外部服务。汉字保持原始可访问名称，拼音作为视觉辅助，输入值不改写。

界面保留蓝绿品牌，整理导航、卡片、表单、长文本和触摸目标，验证窄屏、横屏、缩放及状态恢复。iOS 使用 Foundation 核心、原子本地存储与 Keychain 家长凭据，提供主页、挑战、休息、错题、记录、家长设置；系统管控缺少权限时明确报告不可用。不能以模拟用时宣称跨应用限制有效。

曾考虑网页容器以减少重复，但用户选择由实现者决定，采用原生方案以便平台功能接入。Linux 缺 Xcode，必须区分源码检查与 Apple 平台编译/签名/设备验收。发布环境、推送代码不在本次授权内。
