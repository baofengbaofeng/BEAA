# iOS 后续功能一次性源码交付

用户要求本轮完成iOS后续功能，Apple编译测试由用户后续进行；沿用按实现者判断直接开工授权。本轮不发布环境、不推送、不调用真实iCloud/通知/管控权限。所有中文应用界面配拼音，系统面板由系统管理。

## 功能范围
1. 家长安全：改PIN、忘记PIN恢复码、可选择的本机生物识别快速验证；无默认密码，不上传凭据。生物识别默认关闭，明确设备中登记的识别不等同于家长身份。
2. 本机可信存储：AES-GCM封装学习状态、Keychain密钥/高水位、防旧快照回放、文件锁与原子写入；旧明文仅首次受控迁移，保留坏文件。加密备份/检查/恢复须已有家长认证，旧版本备份不能降低当前可信高水位，丢失密钥不能伪造恢复成功。
3. 家长应急授权：可在待挑战阶段分配1–30分钟短时例外，审计、到期/回拨终止。只绕过待挑战，不绕过每日上限、禁用时段、进行中的挑战或休息；不重置已耗尽周期。原有正常子预算保持独立。
4. 学习：打包现有90题基础库（非完整课程，教师仍需审核），年级学科知识点筛选，完整错题复习和阶段统计/报告；补分数与明确绝对误差题型。严格题库校验、旧题/记录迁移、第一答分数语义不变。
5. 系统通知：实际UNUserNotificationCenter申请/状态、5分钟/1分钟/到期提醒、去重与取消；只按当前真实来源的范围描述提醒，不把前台练习说成全设备使用。
6. Screen Time：FamilyControls授权/选取范围、ManagedSettings限制请求、DeviceActivity监控扩展和阈值回执、AppGroup桥、撤权/配置缺失处理。默认未启用，源码/工程/entitlements/配置路径齐备；需开发者填自己的Team/AppGroup并获正式entitlement后运行。监控只覆盖选择的范围；API调用接受不等于真机限制已验收。不能证明眼睛离屏或整台设备没有操作。
7. iCloud与远程家长协作：显式开启的CloudKit账户检查、私有/共享区、CKShare邀请/接收、题库云资产和摘要、版本冲突、远程指令和回执。凭据/原始资格账本不上传。远程指令必须来自本机家长确认的已接受可写分享参与者，带目标、事件ID、期望修订、有效期；拒绝重放/过期/越界，不突破本机每日/休息/禁用限制。无配置时显示需配置而非成功。
8. 用户接手：实际Xcode工程含监控扩展、资源、能力配置模板和测试成员；单独能力矩阵、配置指南、验收步骤及源码打包。

## 架构与文件归属
Root负责AppModel/ParentView与各服务集成、工程生成/校验、文档和交付。
平台任务只创建Platform*、ScreenTime*、Notification*与Extensions/DeviceActivityMonitor文件；云任务只创建Cloud*、Remote*；安全任务修改ParentVault并创建SecureStateStore/Backup*/Security*；学习任务拥有Lifecycle/QuestionBank/AnswerTypes/BEAAApp及Learning*/Emergency*、Resources/及相关测试。各任务不能写Root拥有文件，先报告公共接口再集成。

各功能提交学习状态必须先成功持久化再暴露资格；设备动作随后应用并单独报告状态。系统回执是阈值下界而非任意完整精确用时，不能把未知权限当作已解除。云端不直接覆盖本机资格账本。课程、教师读音、真实家庭效果不是可通过代码代替的门禁。

备选继续仅前台模拟不足以满足本轮要求；直接引入自建后端需要账号/部署，选择Apple原生服务接入源码及关闭的配置入口。所有Apple运行证据明确未产生，不把静态/Node检查冒充XCTest。
