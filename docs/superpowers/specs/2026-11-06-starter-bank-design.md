# 基础练习题库与浏览器导入交付

基于dev cc5cb82，补齐P2实际题量：新增独立starter-questions.json，1–6年级×语文/数学/英语×5题，共90道单选基础练习。既有5道sample与M1/自检/原生UI不改，默认演示和现有测试夹具不自动替换题源。该库用于试用分组，不承诺完整课程、统一课标或教师适龄审核；低年级英语为家长可选基础练习。

采用现有version1共享格式、grade/subject/knowledgePoints校验与组卷。内容为本项目新编题干/讲解，语文使用常见词义与古代诗句常识，英语为基础词汇/词形，数学覆盖整数、运算顺序、小数、分数；不下载商业题库，不新增许可声明。数学30题用独立Python AST/Fraction计算与数值选项唯一性核对，语言60题用显式基础事实映射回归；均不等同于独立教师审核。

交付两个JSON格式：共享目录可直接导入version1格式；浏览器数组保留id/grade/subject/题干/选项/正确索引/讲解，按既有受支持分类将math映射arithmetic、chinese映射poetry（UI称语言积累）、english映射vocabulary。浏览器数组按两空格缩进并带末尾换行的实际交付文本不得超过2,000,000 UTF16码元，恰好上限允许；超出整体上限必须在输出前拒绝。细粒度knowledgePoints仅在共享格式保留，浏览器不扩展静态知识点列表。严格拒绝超过浏览器ID/文本长度限制的题，不截断、不丢题或错误转换答案。

用无依赖Node脚本生成确定性共享/浏览器JSON、覆盖报告、中文导入说明与SHA256SUMS到dist；构建必须验证18个组合各自可组默认5题，并验证每组共有主知识点也能组5题。报告educatorReview=pending/curriculumAlignmentVerified=false，不能把结构/组卷测试当课程审核。所有内容与覆盖校验通过后才生成/更新专用dist目录中的五个产物；非法输入时不创建新输出、不修改已有交付，目录中的无关文件保持不变。不承诺跨文件系统写失败的原子事务，使用校验和检查完整性。

浏览器验收用实际导出文件经现有家长验证/导入界面，18个年级学科分别答完5题，保留导入前累计、窄屏与刷新进度，确认通过但仍待休息。只测试模拟使用，不证明跨应用管控或健康效果。没有公共部署。
