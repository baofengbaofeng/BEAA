# 判断题与数值填空

沿用用户按判断直接开工的授权，扩展现有客户端离线题库、挑战、错题和恢复流程。保留所有旧单选题及默认题库，新增可导入混合样例。所有应用控制的中文继续配声调拼音。

客户端数组题库兼容旧题，单选可省略type或为single_choice。判断题为type:true_false，options固定["正确","错误"]，answer为0或1。数值填空为type:numeric，answer为规范十进制字符串，不允许options字段；公共字段仍为id/grade/subject/topic/text/explain，旧长度与分类限制不变。参考用的共享v1单选目录/SQLite资格账本保持严格v1，不把新的客户端数组错误宣称为该参考格式的新版本。

数字输入使用精确字符串规格，不做浮点近似。接受首尾空白、正负号、全角数字/符号、小数及前导零；最多12位整数及6位小数，输入最长48字符。整数或小数至少有一个数字，.5和2.可规范化；零不保留负号，去除多余零。拒绝单位、逗号、分数、科学计数法、NaN/Infinity及内部空白。题库中的标准答案必须已规范化。

格式无效不计入首次尝试、不新增错题。有效错误答案保留首次得分为0并要求纠正；纠正后推进但不得提高首次正确率。数字答案按规范字符串持久化到错题，不转成选项下标。当前挑战固定题快照；导入、刷新、禁用时段、休息、每日上限、并发与家长授权边界保持有效。错题复习不发放资格或改写挑战得分。

网页使用文本输入+decimal键盘提示与明确提交按钮，Enter可提交。输入和题库文本以纯文本显示，拼音不改写输入。数字草稿仅存在当前页面，提交后持久化答案结果；未提交草稿刷新会丢失。判断题使用同样大小的二选一按钮。iOS采用对应原生输入与模型，旧Question解码默认单选；Apple编译与XCTest仍依赖Mac/Xcode。

本批不加入分数、误差容忍、代数表达式、题库教学质量认证或云服务，也不发布环境。
