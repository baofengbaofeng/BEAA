# 整体功能与阶段交付设计

沿用已验收浏览器、共享业务组件和原生工程，不另建项目。用户要求一次连续交付，常规实现选择由开发者决定，跳过逐项方案确认。

## 本轮目标与实现选择

1. 浏览器接上5/1分钟页面提醒及更细模拟步长，显示周期与日余量较小值，不发系统通知。
2. 增加家长验证后的临时使用时段：仅在AVAILABLE且已满足原答题/休息规则时分配，1–30分钟，不能超本轮/当日余量，同时限制墙钟有效期和使用预算。到期/耗尽/回拨/撤销后停止此时段，须家长结束临时模式或新建时段；不会自动退回普通可用状态。明确这是一项收紧正常资格的限额功能，不绕过挑战/休息、不增加每日额度。共享纯模块校验与计算，浏览器存储/认证和审计接入。
3. 家长页显示有界审计记录，导出脱敏学习摘要；导出不带PIN/hash/salt/授权或完整存储副本。
4. 恢复损坏的关键时间/权限数据时封闭可用路径并保留原始文本；不把解析失败当首次建立。跨日保留周期挑战义务。存储失败禁止使用/发资格，提供显式保存重试。
5. 原生工程新增/使用ArkWeb离线入口复用同一已测试页面，打包脚本生成rawfile并校验同步，不提供JS权限桥/网络能力。旧ArkUI演示保留为历史源文件（非主入口）。此选择避免重复移植两个规则引擎；代价是WebView存储/PIN仍为演示级，不能声称原生安全存储或真实管控已实现。匹配SDK/签名/设备均缺，编译与设备验收保持阻塞。
6. 统一交付命令产出浏览器、规则自查、题库、源码、文档/测试索引和校验和；命令不发布/部署，不收集真实儿童数据或运行库。

替代方案：继续独立移植ArkTS会产生未经SDK验证的第二份逻辑；构建全新服务端改变离线定位。本轮采用现有单页/纯模块和离线原生容器，由开发者作实施选择。

## 契约与不变量

临时时段模块独立，无Guardian schema变更：createTemporaryAccess(request, trustedContext)、validateTemporaryAccess(value)、observeTemporaryAccess(value, {nowMs,usedSeconds})、getTemporaryAccessStatus(value, trustedContext)、closeTemporaryAccess(value, nowMs)。可信上下文包含phase、周期/日余量和nowMs；模块不能验证权限或真实时间，宿主在身份验证和持久提交后才使用。无时段时正常规则继续；有已结束时段时不自动放行。纯模块在构建时嵌入现有单HTML，与ESM源字节对应，保持无网络依赖。

恢复安全：可选错题/历史的损坏可忽略，不丢PIN/日累计；不可解析JSON、关键计数/日期或PIN配对损坏必须显示恢复阻塞且禁止写回。只能由用户通过明确的外部数据恢复/站点清除手动处理，不能一键自动重置额度。存储保存失败保持提示并阻止关键操作。

## 验证与边界

纯模块：端点、非法字段、回拨/过期/耗尽/取消、阶段/额度拒绝、重复观察/深拷贝。浏览器：授权/审计/到期/每日上限/休息拒绝、刷新/多标签页、导出无凭据、提醒与恢复；实际Playwright、axe和现有38项回归。原生仅静态路由/资源同步与完整离线页面浏览器回归，不当作SDK编译证据。交付索引逐条映射原始10项需求，列明已测试/仅源码/待人工，不用一个总“完成”覆盖设备门禁。数值填空、禁用时段、远程端等非原始10项扩展列明未实现；不得声称全产品验收。
