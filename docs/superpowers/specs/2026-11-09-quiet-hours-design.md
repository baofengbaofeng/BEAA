# 每周禁用时段

延续用户按实现者判断直接开工的授权，先实现剩余清单中不依赖设备 SDK 的每周禁用时段。共享 JavaScript 规则、浏览器/鸿蒙页面和独立 SwiftUI 实现采用一致语义。

时段结构为 `{days:[1...7],startMinute:0...1439,endMinute:0...1439}`，周一为1，周日为7；days 指开始日期。最多14条，每条至少一个不重复星期；开始等于结束无效。开始含边界，结束不含边界；结束早于开始表示跨午夜，凌晨属于前一天开始的时段。重叠时段取并集。空数组表示关闭，旧存档缺少字段迁移为空数组，显式无效配置保留原始数据并进入恢复保护。

按当前设备本地时间判定。取不到有效本地时间时，有时段配置则暂停使用。时间回拨触发的既有保护不被时段结束绕过。未声称具有可信时间或系统管控能力；夏令时/时区变更按设备实际本地星期和分钟重新判定。

禁用时段独立于业务阶段，不清零每日/周期累计、答题、休息或历史。期间不累计应用内使用或休息，不允许开始/作答/完成休息或发起临时额度。家长验证、修改禁用时段、结束临时模式、导出摘要、查看记录仍可进行。进入禁用时段终止活动临时时段（保留审计）；退出时段不重建额度，继续原业务阶段。原每日上限同样保持有效。

家长验证后可选择星期、开始/结束时间并添加/删除时段，立即原子保存，输入无效不破坏旧设置；可在挑战或休息期间修改独立的禁用时段，避免无法纠正配置。界面明确显示暂停原因和本机时间依据，全部中文带拼音；系统时间选择器语言由平台控制。

备选每日单时段不足以覆盖周末；云端远程排程需要账号与服务，暂不采用。无云服务、不发布环境，Apple 编译与设备 SDK 门禁不变。
