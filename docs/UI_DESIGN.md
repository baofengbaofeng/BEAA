# UI设计规范 v0.1

## 品牌
产品仅显示“学知守护”；不得在产品界面展示任何设备厂商、操作系统、平台Logo。柔和蓝绿、圆角卡片、充足留白、大字号中文、儿童教育插画；避免过度刺激。

## 自适应
以可用窗口宽度而非单纯物理方向决定断点和布局：
| 页面 | 宽屏 | 窄屏 |
|---|---|---|
| 儿童主页 | 倒计时左、统计右 | 倒计时上、统计下 |
| 学习挑战 | 题目与选项两栏 | 题目上、按钮纵向排列 |
| 成功解锁 | 插画与资格并排 | 插画、文字、休息按钮纵排 |
| 家长设置 | 左导航右内容 | 顶部导航，内容可滚动 |

## 交互要求
- 旋转不丢题目、已选答案、剩余时间或授予状态，不允许重复提交。
- 窄屏与分屏可滚动；大按钮、足够点击区域和可访问的对比度。
- 展示“资格获得”与“实际可使用”不同状态，先完成休息再恢复访问。
- 中文示例：剩余30分钟、每日上限120分钟；小学三年级数学第3/5题：36÷4+7=?（答案16）。
- 设计展示图为视觉参考，不是系统权限或可运行功能的证明。
