# 业务规则原型（Node.js）

这是纯 JavaScript 领域逻辑与单元测试，不是已经可安装的HarmonyOS应用，也不具备系统锁定权限。

运行：在仓库根目录执行 `npm test` 或 `npm run demo`（Node.js 20+）。

能力：30分钟周期、120分钟每日硬上限、逐题判定、通过后休息、完成休息再发放下一轮资格、可信日切换。

边界：计时事件、休息时长、标准答案和日期必须由可信设备/题库服务提供。生产应用还需要持久化、夜间规则、异常恢复、权限生命周期及系统 API 集成。

`recordUsage` 接收已核实的有效使用秒数，因此单次超过一个周期的事件可以先触发挑战或日上限；实际适配器应按事件边界采样并及时执行限制。
