# 学知守护 · 无设备浏览器交互原型

这是一份**独立 HTML 文件**。无需 DevEco Studio、HarmonyOS 真机、npm 或后端服务即可演示产品流程。

## 使用
1. 打开 `index.html` 即可预览；可用电脑浏览器“响应式设备模拟”检查横竖屏布局。
2. 首页点击“模拟用满当前周期”触发学习挑战；完成全部题目后看到下一轮资格和休息要求。
3. 家长设置可调整时长、年级、题量；设置与流程进度存储在浏览器 `localStorage` 中。
4. 默认休息10分钟采用真实经过的浏览器时间判定；测试时可以在家长设置临时改为0分钟。

## 重要边界
- 全部使用时间均为**人工模拟数据**，不是跨应用真实屏幕时间；不能锁定/解锁任何其他软件。
- 浏览器存储适合演示，不具备生产级防篡改和家长保护。
- 题库演示只含5道固定题，答错可重试；正式版本应使用独立题库服务和合理的再练习策略。
- 页面可根据浏览器宽度切换单栏/双栏，不依赖厂商品牌。
- 手机/平板浏览器页签长期后台运行时，不承诺计时准确性。
