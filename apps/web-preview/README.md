# 学知守护 · 浏览器 MVP 演示

本版本是一份独立 HTML，不需要后端。沿用原型实现，不具备设备管控权限；所有使用分钟由按钮模拟，不能统计或限制其他应用。

## 运行与验证

- 使用现代浏览器打开 `index.html`。若浏览器禁止 `file://` 或无法使用本地存储/Web Crypto，请在仓库根目录执行 `python3 -m http.server 4173 --bind 127.0.0.1`，在本机浏览器访问该服务的 `/apps/web-preview/` 路径。若使用解压后的独立演示包，则在含 `index.html` 的目录运行同一命令，访问服务根路径。开发测试命令需在完整源码仓库运行。
- 首页模拟满周期，按题目答题。默认首次作答需 5/5 正确；答错会解释，必须纠正才能进入下一题，但重试不会提高首次正确数。本轮不通过可重新挑战。
- 通过仅获得待生效资格，仍需经过休息；点击“检查休息条件”核对经过时间。日上限优先，不能靠答题突破。按本机日期向后跨日时清零日累计，进行中的答题/休息保留。
- 家长首次设置 6–12 位数字 PIN，后续验证才能更改规则、导入题库、重置。授权五分钟；刷新或主动锁定即失效；连续五次错误会冷却一分钟。忘记 PIN 需清除站点数据，所有进度也会丢失。
- 挑战和休息期间不允许修改规则或题库。错题本可再次选择答案；学习记录显示最近挑战与首次正确率。
- 在根目录运行 `npm ci`、`npm test`、`npx playwright install --with-deps chromium`、`npm run test:browser`。已有 Chromium 时可设置 `BEAA_CHROMIUM_PATH=/usr/bin/chromium`。本云环境 npm 缓存需写入允许位置：`npm ci --cache /workspace/.npm-cache`。
- `npm run build:demo` 产生 `dist/beaa-web-demo.zip`、独立 HTML、使用说明、题库样例及 SHA256SUMS；这只是打包，不是原生编译。CI 自动保存测试报告、失败追踪与演示包。

## 配置题库

内置 95 道流程样例（六个年级各 15 道，加上原有五道三年级题），不代表完整课程或教学质量验收。年级、学科和知识点会实际过滤题目；按库内顺序选择不同 ID 的题目。题量不足会拒绝开始，不重复凑题。可在家长设置中导入 JSON **数组**，整体替换内置题库；默认策略 5 题，导入后需有足够匹配题目，或修改题量。

```json
[
  {
    "id": "math-g3-add-001", "grade": 3,
    "subject": "math", "topic": "arithmetic",
    "text": "15 + 17 = ?", "options": ["31", "32", "33"],
    "answer": 1, "explain": "15+17=32。"
  }
]
```

`answer` 从零开始。学科：`chinese`、`math`、`english`；知识点：`poetry`（语言积累）、`arithmetic`（计算）、`vocabulary`（词汇）。题库最多 2000 道、输入最多 2 MB；ID 唯一，答案必须指向有效选项，不能有重复选项。题干与选项以纯文本显示，导入 HTML 不执行。

## 数据与能力边界

- localStorage 键：`beaa-web-preview-v1`。保存规则、待答题快照、首次正确数、错题（最近 200 条）、挑战（最近 200 次）、最近 100 条家长操作事件、导入题库及加盐 PIN 摘要。刷新恢复时校验类型、范围和状态一致性；已有快照启动只读，状态和版本基于同一次读取，避免新标签页启动回写覆盖其他页进度；旧原型缺少快照的进行中挑战会回退到需重新挑战，保留使用累计。
- PIN 使用 Web Crypto PBKDF2-SHA256（10 万次、随机盐），不保存明文。首次设置须由家长完成。本地数据可被修改或清除；此验证不是生产级儿童防绕过机制。不要使用真实常用密码，不录入儿童个人信息。
- 回拨会暂停休息资格至时钟恢复；向前改时钟、跨日以及清除数据可绕过本地规则。本产品演示无法提供可信时钟或真实离屏检测，不作设备安全保证。
- 浏览器拒绝存储/配额不足时显示“无法保存”，仍可临时体验，但关闭后可能丢进度。现代浏览器使用 Web Locks 串行处理标签页操作，并同步最新快照；其他标签页更新会撤销当前家长授权，需重新验证。无 Web Locks 的浏览器仅做快照冲突检测，建议单标签页使用。这不是跨设备同步。
- 自动化覆盖 Chromium；不代表所有浏览器、读屏器或真实平板均已验收。云 Chromium 策略可能拒绝 `file://`，本地对应测试明确标记 skipped，HTTP 下离线闭环单独验证；CI 下该项禁止策略性跳过，必须验证独立文件打开。

## 集中交付新增功能

- 主页增加模拟1分钟步长与5/1分钟页面提示；显示周期/日余量的较小值。未发送系统通知。
- 家长验证后可分配1–30分钟的临时使用时段，同时限制有效期和使用预算，不能超过正常周期/日余量；不跳过答题、休息或日上限。时段耗尽、到期或时间回拨后保持停止，家长需在设置页“结束临时模式”或重新分配。结束模式不清空累计，仍按正常规则判定资格。
- 家长页可查看最近100条操作审计，下载不含PIN/hash/salt/token的学习摘要JSON。摘要为本机最近200次挑战的演示记录，不是健康或教学效果证明。
- 同一HTTP来源的多个标签页共用存储并通过Web Locks串行操作；家长登录状态不跨页共享。file://模式受浏览器存储/锁策略限制，不具备同等并发保证。

## 克隆后本地运行

```bash
git clone -b dev https://github.com/baofengbaofeng/BEAA.git
cd BEAA
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/apps/web-preview/`。Windows可用 `py -m http.server 4173 --bind 127.0.0.1`。首次进入“家长设置”自行设置6–12位数字PIN；预览本身不要求安装npm依赖。源码中没有默认家长PIN。

开发测试需要Node20+、Python3.11+：`npm ci`，再运行`npm test`。真实浏览器测试先`npx playwright install chromium`，再`npm run test:browser`。这些命令不编译原生HAP。

## 数据恢复与存储权限

出现“数据需要恢复”时，关键计数、日期、临时时段或PIN配对未通过检查；原始存储不会被自动覆写。先停止操作，在浏览器开发工具的Application/应用程序→Local Storage中，将`beaa-web-preview-v1`的原始值保存到本机私有文件；它可能含PIN派生摘要与儿童记录，不要公开发送。由开发者核对原始副本及已知有效备份后恢复，勿把删掉记录重新开始当作恢复成功。无可验证备份时不能自动重建原使用累计。

出现“无法保存本地数据”时，关键操作暂停。恢复该来源的浏览器存储权限/磁盘空间后点“重试保存”；失败期间不显示新资格为可用。清除站点数据会丢失累计和PIN，只能作为持有人明确决定的演示重置，不能证明防绕过有效。

原生离线容器仍需实测WebView的WebCrypto、本地存储、下载、进程恢复和方向变化；浏览器通过不能替代这些原生验收。
