# 学知守护 · iPhone / iPad

iOS / iPadOS 17+ SwiftUI 客户端。本轮按用户要求完成后续功能源码；Apple 编译、XCTest、签名与真机验收由用户后续执行，当前没有对应通过结果。

## 已实现的源码

- 学习：首页、挑战、首次答案评分和订正、休息、最近一百轮错题复习、按日与学科统计；内置九十道小学语数英样题，可按年级、学科和主题筛选并导入题库。
- 题型：单选、判断、精确十进制、约分分数、显式绝对误差容忍。保留旧格式，容忍值不会隐式套用到精确数值题。复杂题型格式见 [说明](../../docs/ANSWER_TYPES.md)。
- 家长：六位密码、失败冷却、修改密码、一次性恢复码、可选生物识别；授权最多五分钟，后台撤销，敏感子页面随授权失效隐藏。
- 记录：AES-GCM 加密、Keychain 修订锚、进程锁和原子替换、精确匹配当前可信修订的崩溃恢复日志；同设备最新加密备份检查与确认恢复，拒绝旧账本回退。详见 [本机安全](../../docs/IOS_SECURITY.md)。
- 授权：原额度内临时子预算与等待挑战时的应急授权分开；应急不会绕过休息、进行中的挑战、禁用时段或每日上限。记录有界审计。
- 系统：可选使用范围选择、用时阈值、所选应用/类别/网站限制、禁用时段及授权到期监控、通知；包含监控、限制界面和限制按钮三个扩展。详见 [平台配置](../../docs/IOS_PLATFORM_SETUP.md)。
- 家庭：可选云端摘要、家庭分享、参与者本机确认、题库资源上传下载、规则/应急/结束授权指令与回执。具备来源、目标设备、控制修订、过期和重放检查。详见 [云端配置](../../docs/IOS_CLOUD_SETUP.md)。
- 显示：中文应用提示统一使用带声调拼音组件；通知、限制扩展和生物识别原因也附拼音。系统键盘、文件面板、权限面板中的系统文本由系统管理。宽屏两栏、窄屏滚动、大点击区及儿童学习/复习/家长入口分别呈现。自动拼音与九十道样题仍需人工教学审核。

## 两种构建

`BEAA` 是默认练习方案：不嵌入扩展，不启用系统管控或云服务，无需受限能力；仅累计本应用前台练习时间。

`BEAAConnected` 嵌入三个扩展并打开能力配置入口。必须复制 `Configuration/User.xcconfig.example` 为忽略的 `User.xcconfig`，填写自己的团队、Bundle ID、App Group 和云容器，配置能力与签名。构建开关开启后，用户仍须在家长界面主动授权/开启，不会默认上传数据或请求系统权限。模板标识不能用于正式签名。

所选范围回执为累计用时下界，用 MAX 投影而非相加；系统模式不重复计入前台秒数。停止、重新开始或修改监控时间/禁用时段会保守结算尚未确认的当前预算。到期回执先持久化关闭并结算授权，再确认处理。它不是整机精确用时，也不承诺普通应用不可绕过。

休息模式在可确认的同设备启动、同监控代次、同规则修订和连续时钟区间内支持后台恢复；条件不完整时不补时间。限制所选范围不能证明儿童没有使用其他设备或没有看屏幕。跨日由家长确认，保留未完学习阶段；时间规则变更在安全阶段生效。

## 后续在 Mac 验证

需要 Xcode 16+ 及实际安装的模拟器：

```sh
cd apps/ios
python3 validate_project.py
open BEAA.xcodeproj
xcrun simctl list devices available
xcodebuild -project BEAA.xcodeproj -scheme BEAA \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  CODE_SIGNING_ALLOWED=NO test
```

按实际模拟器名称替换。Connected 方案还需独立构建三个扩展并在有权限的真机上验收。现有 CI 源码保留练习方案测试，可在配置后运行；本轮未触发远程工作流。

`generate_project.py` 可重复生成项目；自定义配置放在 `User.xcconfig`。`generate_project.py --check` 和 `validate_project.py` 是只读结构检查，发现本地项目差异时不会覆盖它。它们不解析 Swift 类型、不链接框架，也不执行 XCTest。

交付与待验收清单见 [本轮报告](../../docs/testing/IOS_COMPLETION_REPORT.md)。没有发布或推送任何内容。

## 跨设备迁移

新增独立口令加密的跨设备迁移，不改变原有同机备份规则。目标必须是未使用的新账本；导入后保留来源累计/未完挑战并锁定，家长确认后将原累计计入今天。新安装在家长设置前不自动计入练习时间；家长配置期间暂停本应用练习采样。系统监控开启时导出前先处理回执并保守结算未知用时。入口为家长工具中的“跨设备加密迁移”。[迁移安全和验收说明](../../docs/IOS_MIGRATION.md)。新增XCTest源代码未执行。
