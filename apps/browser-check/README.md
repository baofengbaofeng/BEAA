# 浏览器规则检查（无需安装）

取得 `dist/beaa-browser-check.html`，用支持 JavaScript 和 WebCrypto 的现代浏览器打开，点击「开始检查」，完成后点击「下载检查报告」。不需要 Node、Python 或开发工具。首次运行无需网络，所有演示源码已嵌入文件。

检查使用与项目相同的浏览器 MVP 源码，在独立 iframe 中替换存储、状态锁与时钟后才执行。模拟数据仅在内存中，不读取/写入用户的 localStorage，不上传报告。源码校验失败会阻止执行；隔离不支持会显示未完成。请勿手动编辑 HTML，完整性摘要用于发现意外损坏，并非签名或来源认证。

六项检查：失败答题与错题/统计、休息十分钟边界、每日120分钟上限、内存快照重载与宽窄尺寸、家长PIN和设置恢复、时钟回拨暂停。约数秒完成；不会实际等待十分钟。固定样例题不代表题库质量全面验收。

报告中的 `passed` 仅表示列出的隔离模拟检查通过。它不验证真实浏览器磁盘持久化、跨标签并发、操作系统横竖屏事件、跨应用计时/锁定、原生编译或医学/健康效果。后续需要目标设备权限与安装验证；改善用屏行为需家庭试用记录支持，不能用本页报告代替。

如果浏览器阻止本地HTML、加密接口不可用或报告未完成，请保留报告给开发人员；不要把未完成视作通过。可以在有条件时由开发者提供安全的内部预览链接，本仓库不会自动部署公共网站。

开发者：`npm run build:browser-check` 生成单文件；`npm run test:browser` 会先打包再验证。开发预览路径 `/apps/browser-check/` 会从同源加载 MVP 文件；交付文件使用嵌入源码，无外部请求。
