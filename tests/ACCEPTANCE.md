# MVP 验收测试

拿到设备后的工具/连接、权限验证、真实构建与逐步操作见[验收手册](../docs/DEVICE_POC.md)，执行时复制[记录模板](../docs/testing/DEVICE_ACCEPTANCE_RECORD_TEMPLATE.md)。本文为验收基线，未执行不得标通过；当前演示骨架不代表已具备以下系统能力。

| ID | 场景 | 期望 |
|---|---|---|
| A01 | 使用满30分钟 | 触发挑战；受支持的纳管应用限制生效 |
| A02 | 应用切换 | 累计计时不清零 |
| A03 | 息屏 | 有效使用计时暂停，记录不丢失 |
| A04 | 5道题全对 | 发放待生效资格 |
| A05 | 答对4/5题 | 严格模式不通过、展示讲解 |
| A06 | 全对但休息未满10分钟 | 不提前解除限制 |
| A07 | 每日使用达120分钟 | 答题不能突破硬上限 |
| A08 | 横竖屏旋转 | 题号、选择、计时与授权状态不丢 |
| A09 | 断网 | 题库和本地策略可用 |
| A10 | 重启/崩溃 | 规则持久化，不额外放行 |
| A11 | 系统时间回拨 | 无额外奖励，记录异常 |
| A12 | 撤销管控权限 | 准确告警，不假称仍受管控 |
| A13 | 家长临时授权 | 验证身份、记录时限与日志 |
| A14 | 分屏/窄窗口 | 内容完整且操作可访问 |

**注意**：A01及涉及系统限制的场景，以合法权限和真机能力验证为前置条件。
